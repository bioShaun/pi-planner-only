# Native / Lite：真实测试前的阻塞清单

状态基准：Phase3c Root 复核通过之后；本文仅整理现状和放行条件，不授权启动实验或新增实现。本文中的“真实测试”分为 S1 两臂最小链路校准与正式比较；本地 fixture 测试已经在运行，两者不可混称。

**当前结论：尚不能启动 S1 真实两臂校准，更未进入正式比较。直接阻塞 S1 的是三项完整链路证据缺口，以及变更后的 release 验证和新批次冻结/预检。** 这些缺口不等于已经证实代码存在相应 bug；先沿实际链路验证，发现缺失行为后才修复。

## 1. 已经完成，哪些不应重复做

- 共享费用 monitor、公共 required-child registry 及若干真实 host 本地 stream 测试已有功能证据。
- runner 已初始化本臂独立 monitor 目录，并将目录和 Root monitor 扩展交给启动进程。
- runner 每 100 ms 检查本臂 stop.json；标记存在或检查发生非 ENOENT 错误时，拒绝成功、记录原因并终止直属 Pi。SIGTERM 后仍存活则在 500 ms 后升级 SIGKILL，成功收尾和最终退出前复查。
- Phase3c 聚焦测试 13/13、controller/stage-a/monitor 三文件组合回归 56/56 通过。该结果只覆盖这些本地测试，不是完整实验通过。
- checksum、unbound/reload、corrupt-state 的既有测试时序例外已获限定批准，不再作为待用户决定的问题；历史记录保留，新行为仍需先有效红灯、Root 复核、再授权实现。

依据：[Phase3b 复核](phase3b-final-root-review.md)、[Phase3c 复核](phase3c-final-root-review.md)、[checksum 例外与 S1 阶段授权](checksum-exception-and-s1-authorization.md)、[两处历史时序例外](phase3b-root-authorization.md)。

现有默认全局依赖缺失问题仍有记录；此前使用隔离 PI_SUBAGENTS_DIR 获得了适用测试证据。该问题不是无条件要求“修好所有全局环境”，但必须证明测试、冻结和真实校准实际解析的依赖一致且可用。隔离环境通过不能自动外推到全局安装。

## 3. S1 校准通过后，正式比较还缺什么

**S1 校准通过不等于允许立即做正式四臂比较。** 当前协议还保留以下阶段门，不能因收缩准备工作而静默删掉：

| 后续阶段 | 当前状态 | 要证明的事 |
| --- | --- | --- |
| S1-native → S1-lite 最小真实链路校准 | 已有阶段授权；尚未获得当前新批次的单臂启动放行，也无通过结论 | 真实请求、child 创建、终态、报告、Root 内容决定与费用证据能连起来。每臂一次、300000 ms、reported 停止线 USD1.25；失败即停，不自动重试。 |
| 语义 A–D 校准 | 尚未放行 | Root 能按既定范围正确处理可回答问题、允许的外部 unknown、证据不足和角色越界；不能仅凭 JSON 格式正确判定内容正确。 |
| S2 拓扑校准 | 尚未放行 | validator/oracle 与独立无 shell reviewer 的实际委派、报告和分角色验收正确；S1 单 worker 通过不能替代。 |
| 正式比较 | 尚未放行；历史有效样本 0、完整 pair 0 | 前述门通过后，审查预算和证据，准备并冻结正式四臂，再逐臂放行。保留所有尝试、失败和拒绝，按协议判断哪些结果可比较。 |

## 4. 为什么准备拖长，以及本次收缩边界

原来的执行基础设施暴露了运行中 child 费用覆盖和停止清理缺口；这些影响预算与比较可信度，不能直接忽略。但推进方式按单个组件持续拆小步，造成局部证据越来越多，完整链路一直没有验收。Root 未及时设定统一终点，是准备迟迟不能结束的原因之一。

后续准备的终点限定为：**B1–B3 实际链路证据齐全，B4 适用 release 通过，B5 当前批次材料可审查并通过单臂 gate。** 不追求穷尽所有并发时序、不证明 provider 发票硬上限、不扩展成通用监控平台、不因历史记录需要而重跑所有无关测试。

如发现必须修改候选产品代码、全局插件，或无法在离线环境驱动实际委派链路，应提交精确阻塞与范围冲突，停止追加零碎实现；当前许可不能覆盖这些扩展。新发现的问题只有直接阻断上表放行条件时才进入必修范围。

执行与测试仍由子代理负责，Root 负责范围、有效红灯审核、单独实现授权及实际 diff/原始结果验收。已有行为直接通过应如实记录，不删除正确实现来制造红灯。
