## 1. P1-B（缩窄范围，已向用户说明）

上游 pi-subagents 0.69.0 只公开 REQUEST/STARTED/UPDATE/RESPONSE/CANCEL，没有 finish/grace 事件，非 completed 终态不返回原文。因此：

| 子项 | 处置 |
|---|---|
| 预算前 partial grace | 不实现。能力矩阵与 CONTEXT 显式标 unsupported，代码里不得出现文本降级或猜测 |
| 原始格式错误报告诊断 | 不实现。同上 |
| report-only 修复的权限强制 | **实现**：零工具预算 |

### 实现要点

- 机制：安装版接受 `toolBudget: { hard: 0, block: "*" }`（`src/slash/delegation-request.ts:90` 用 `minimumHard: 0`；`src/runs/shared/tool-budget.ts:57` 的 `block === "*"` 拦所有工具；executor 7484 行读 `delegatedAllowZeroToolBudget`）。第一次工具调用即被拦，终态 failure reason 为 `tool_budget_exhausted`（`delegation-adapters.ts:340`）。
- 接线点：worker Request 在 `delegate.ts:1052` 构造，目前不送 toolBudget。reportOnly 的标记来源：`orchestrate.ts:206`、`orchestrate.ts:1896`、`task.ts:539`；`types.ts:577` 有字段说明。只在 reportOnly 修复轮加 toolBudget；普通 worker/explorer/reviewer Request 不变。
- 账本：ledger 记录该轮送出的 toolBudget 与终态；`tool_budget_exhausted` 映射为明确的失败家族（不是 task-quality），并保留原始 terminal。report-only 轮的报告不得新增 truthPaths（现有 `delegate.ts:1550/1893/1897` 的过滤要保持）。
- reportOnly 标记不可由重入参数翻转；一次修复用完后按 `types.ts:24` 的规则 block。
- 不改系统安装的 pi-subagents；不 import 上游 raw TypeScript，只走版本化事件契约。
- ADR-0009：report-only 修复通过零工具预算强制；写明 0.69.0 依据、不支持项和退出条件。CONTEXT.md、README、README.zh-CN、transport-capabilities.md 同步。

### 测试与证据（我审核时逐条核对）
