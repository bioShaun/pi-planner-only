## 解释边界

- A 两例指向“交接可省”的具体机会，但不是证明 child 的读文件或复核无价值；尤其首次 README 有遗漏并经历第二次派发。B 里的 TDD、故障注入、隔离 worktree 和真实契约验证是观察到的收益，不证明只有 child 才能完成。历史上 Root 可否立即完成、以及两种路径的正确率、总成本与延迟均是反事实。
- Root 与 child 常在同一会话连续工作，同一功能的首次实现和返工不是独立试验；模式标记证明行为所处模式，不证明特定系统提示在当时如何影响每一次决策。历史用户授权、技能、工作区并行和验证要求均可能约束选择。
- 未计算费用或耗时：没有逐事件一致地关联 Root 后续审查、并发时间、重试、账单和反事实，因此 child 总费用不等于可节省费用；也不把延迟相加当 wall time。
- 结果不能外推其他仓库、其他 Root 模型、全部 Native workflow、独立审查、不同任务大小，亦不能从 P2 的四次有效样本推断哪种指令更好。P2 仍按费用未知暂停，不恢复实验。
