Write a new standalone Python 3 script `script/variant/deg_variant_assoc.py` (stdlib only: gzip, csv, argparse, collections; no pysam/pandas) that links differentially expressed genes (DEGs) with SnpEff-annotated variants per contrast — the standard "差异基因与变异关联分析". Do NOT modify any other file (Nextflow wiring and report are done separately).

Inputs (argparse):
- `--vcf` annotated cohort VCF (.vcf.gz or .vcf) with SnpEff ANN in INFO. Smoke example: /home/project/rnaseq/TC-BSR-20260821-ZHZ015/test_integrated/work/07/aac5e6fc5b751b7f25b066067c8379/cohort.snpeff.vcf.gz (samples XM-7ZH5 XM-Z1 XM-Z1R XM-Z1S; FORMAT GT:AD:DP:GQ:...).
- `--sample-group` TSV `sample<TAB>group` (no header; ignore blank/# lines). Smoke: /home/project/rnaseq/TC-BSR-20260821-ZHZ015/test_integrated/sample_group.txt
- `--contrast` TSV `groupA<TAB>groupB` per line; contrast name = `{A}_vs_{B}`. Smoke: /home/project/rnaseq/TC-BSR-20260821-ZHZ015/test_integrated/results_pipe/smoke_pipe/configure/contrast.ini
- `--diff-dir` directory containing per-contrast subdirs `{name}/{name}.edgeR.DE_results.txt` (full edgeR table, header: Gene_ID Locus gene_name gene_description <sample>_TMM_count... <sample>_TPM... logFC PValue FDR) and `{name}/{name}.ALL.edgeR.DE_results.diffgenes.txt` (headerless, one DEG Gene_ID per line). Smoke: /home/project/rnaseq/TC-BSR-20260821-ZHZ015/test_integrated/results_pipe/smoke_pipe/result/quantification/differential_analysis . Also accept a layout where the subdirs are staged flat under the given dir via symlinks (just glob `*/{name}.edgeR.DE_results.txt` recursively one level, and also `{name}.edgeR.DE_results.txt` directly in diff-dir). Skip contrasts whose files are missing with a stderr warning.
- `--outdir` (created), `--min-dp` default 5, `--min-af-diff` default 0.5, `--preview-rows` default 50, `--pass-only` flag default on (keep FILTER in {PASS, .}); allow `--no-pass-only`.

Logic:
1. Load DEG sets per contrast; DEG direction from logFC in the full table (UP if >0 else DOWN); keep logFC, FDR, gene_name, gene_description for DEGs. Union of all DEG ids = target gene set.
2. Stream the VCF once. For each variant (skip non-PASS if pass-only), parse ANN entries (comma-separated; fields `Allele|Annotation|Annotation_Impact|Gene_Name|Gene_ID|Feature_Type|Feature_ID|Transcript_BioType|Rank|HGVS.c|HGVS.p|...`). Skip entries whose Annotation (may be `&`-joined) consists only of intergenic_region / upstream_gene_variant / downstream_gene_variant / intergenic-like terms. Map each remaining entry to a DEG id by normalizing Gene_ID then Gene_Name: strip a leading `GENE_` prefix; if not in target set, split on '-' is NOT done; progressively drop trailing `.xxx` segments (e.g. `TraesCS1A02G001800.1.exon1` -> `TraesCS1A02G001800.1` -> `TraesCS1A02G001800`) until matched. Per (variant, gene) keep the most severe entry (HIGH > MODERATE > LOW > MODIFIER) and its effect term, HGVS.c, HGVS.p. Variant type: SNP if all REF/ALT alleles length 1 else INDEL (skip `*` alt).
   Only keep variants that hit at least one target gene (memory: wheat VCFs can have millions of records; store per gene only the needed fields + per-sample genotype info).
3. Per sample genotype: GT (handle `/` and `|`, missing `.`), DP from FORMAT DP (fallback sum of AD); sample counted as called only if GT not missing and DP >= min-dp. Alt dosage = fraction of non-zero alleles in GT.
4. For each contrast and each DEG in it, for each linked variant: group A / group B samples from sample-group; AF_A, AF_B = mean dosage over called samples of that group; group_genotype string = most common GT among called samples (ties: first sorted), or `NA` if none called. Group-differential if both groups have ≥1 called sample and |AF_A − AF_B| >= min-af-diff.
5. Outputs in outdir:
   a. `{contrast}.DEG_variants.tsv` — all DEG-linked variants (differential or not), header: Gene_ID gene_name gene_description Regulation logFC FDR CHROM POS REF ALT Type Effect Impact HGVS_c HGVS_p {A}_GT {B}_GT {A}_AF {B}_AF AF_diff Group_diff(yes/no) followed by per-sample GT columns for samples of A and B. Sorted by Group_diff yes first, impact severity, FDR.
   b. `deg_variant_summary.csv` (UTF-8, report table, Chinese headers): 比较组 (`A vs B`), 差异基因数, 含变异差异基因数, 含组间差异变异的差异基因数, 其中含 HIGH/MODERATE 差异变异的基因数, 组间差异 SNP 数, 组间差异 InDel 数. One row per contrast (include contrasts with 0 DEGs).
   c. `deg_variant_preview.csv` (report table): top `--preview-rows` rows across all contrasts of group-differential variants only, prioritized by impact severity then FDR, but round-robin/fair across contrasts (e.g. take at most ceil(N/#contrasts) per contrast first, then fill), columns: 比较组, 基因, 上/下调, log2FC (2 decimals), FDR (3 sig figs, scientific), 位置 (`chr:pos`), 变异 (`REF>ALT`, truncate alleles longer than 10 chars with …), 类型, 效应, 影响, A组基因型 (`{A}: GT`), B组基因型 (`{B}: GT`). Header row must exist even when empty.
   d. print a one-line summary per contrast to stderr.
6. Code quality: functions with docstrings, `main()` guard, no global state; handle empty inputs gracefully (write headers only).
