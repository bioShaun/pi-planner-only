# pi-subagents supervisor 消失：公开上游调查

调查日期：2026-10-27。仅查公开 GitHub 内容；没有运行复现或测试、修改配置或向上游发言。本机 0.83.0、Pi 1.4.0 和现场症状是题设信息，不作为上游证据。

## 结论

有相似的公开问题，但未找到一份公开报告同时证明“已收到子代理请求、父会话有 `subagent` 和 `contact_supervisor`、却没有 `subagent_supervisor`”及其根因。最接近的是 [#2916](https://github.com/nicobailon/pi-subagents/issues/2916)：更新后在新进程恢复会话时，包含 `subagent_supervisor` 的支持工具可能保持 inactive；其修复已进入 0.79.0，本机 0.83.0 在版本上晚于该修复，不能因此认定现场同因或已解决。

[#2945](https://github.com/nicobailon/pi-subagents/pull/2945) 从 0.79.1 起有意延迟声明回复工具，但明确要求随 `subagent` 一起激活，并在子请求到达时、唤醒前补声明。故仅以“延迟激活是正常行为”无法解释题设完整症状。不同运行时、实际加载版本、会话历史和请求路径均未由这次调查验证。
