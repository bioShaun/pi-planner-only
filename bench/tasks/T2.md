feat(annotate): REF/ALT 配对接入主流水线，--allele-pair 开关（默认关）

新增 orchestration/_allele_pair_stage.py：把 R6 的 decide_pair_policy 与既有
pair_allele_probes / align_allele_pairs 串成一个 stage，并把宽表折成长表
——— 一条探针一行，REF 与 ALT 平级，供下游按行处理。

折叠口径：
- ALT 行的 13 个列全部有字面 alt_<name> 来源，逐列覆盖，不发明、不默认；
  运行前断言 13 个来源列都在，缺一即抛。
- ALT 行的 off_target_count / median_gap_log10 / off_target_evidence_status
  一律置 NA。这三列来自 REF 的脱靶合并，照抄给 ALT 就是伪造事实。
- probe_id 追加 _ALT 后缀，REF 的 id 原样不动。
- 位点属性列（gene_id / genome_region / site_type / snpEff 效应）随行复制。

插入点在 post_processor.run 之前、且必须在这三步之前，否则各有一种坏法：
- off_target_facts 按 probe_id 合并：ALT 要么继承 REF 的脱靶事实（错），
  要么 join 不上被 fillna(0)，凭空得到一个「零脱靶」的结论；
- SpecificityEvidenceContract.from_annotation：ALT 会进入按 REF 标定的契约，
  改动与本特性无关的 provenance 数字；
- count_self_hit_invariant_mismatches：ALT 与参考差一个碱基，自比对必然是
  1-mismatch 命中，会把审计刷满假告警。

代价（已知，留给后续）：本轮 provenance 与特异性契约不含 ALT，报告章节未接。
